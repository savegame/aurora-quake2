# Quake II для ОС Аврора

[English](README.md) | Русский

Порт Quake II на ОС Аврора.

Quake II — шутер от первого лица, выпущенный студией id Software
в 1997 году. В 2001 году id Software открыла исходный код движка
Quake II (GPL), и сообщество с тех пор поддерживает его сборку
под современные платформы. Этот порт основан на Yamagi Quake II
через форк [Thenesis
Quake II](https://github.com/thenesis-org/lp-public) (подкаталог
`Ports/Quake2`) — исходники оригинального проекта:
https://github.com/thenesis-org/lp-public

Я пишу про новые порты игр на ОС Аврора (на русском) в своём
канале: https://t.me/auroraosgames

## Дисклеймер

В пакете содержится только **движок** игры (открытый исходный код,
GPL). Игровые данные (уровни, текстуры, звуки, `pak0.pak` и
остальные) в пакет **не входят** — они по-прежнему защищены
авторским правом id Software / Bethesda. Для игры нужна легально
приобретённая копия Quake II. Купить можно в Steam:
https://store.steampowered.com/app/2320/Quake_II/

При первом запуске встроенный лаунчер попросит указать папку
с легально приобретёнными игровыми данными; дополнения (Xatrix,
Rogue, CTF) подхватываются автоматически, если лежат рядом
с базовой игрой.

## Особенности порта

- Встроенный in-process лаунчер (Dear ImGui): выбор папки с игровыми
  данными, запуск базовой игры или дополнений (Xatrix, Ground
  Zero/Rogue, CTF), настройка масштаба 3D-рендера — всё до появления
  окна самой игры.
- Тач-интерфейс: виртуальный стик движения, тачпад осмотра и кнопки
  действий во время игры, а также тач-оверлей для навигации по меню —
  в игру можно играть полностью без клавиатуры, мыши и геймпада.
- Поворот и ресайз контента на ОС Аврора: рендер идёт через FBO
  и корректно поворачивается/масштабируется под ориентацию экрана
  устройства (buffer transform поверх Wayland), включая поддержку
  внешнего экрана.
- Экранная клавиатура прямо в игре (тот же интерфейс на Dear ImGui)
  для консоли, чата и текстовых полей — без привязки к системному
  методу ввода.
- Гашение экрана подавляется, пока игра на переднем плане, — даже
  при игре только геймпадом без касаний экрана.
- Поддержка геймпадов через SDL_GameController API со встроенной
  базой маппингов сообщества и определением подключения/отключения
  «на лету».
- Звук через PulseAudio.
- Сборки для aarch64 и armv7hl.
